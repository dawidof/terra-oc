# TerraAuto MVP planning package

Files:

1. `00_PROJECT_OVERVIEW.md` — business/product scope.
2. `01_PAGES_AND_UX.md` — public pages and UX.
3. `02_CAR_DATA_MODEL.md` — detailed vehicle/trim/specification structure.
4. `03_DATABASE.md` — application database and lead snapshots.
5. `04_CONFIGURATOR_COMPARISON_SELECTOR.md` — configuration, comparisons and "Помочь выбрать".
6. `05_CALCULATOR.md` — landed-cost calculator.
7. `06_CRM.md` — admin/manager CRM.
8. `07_SCRAPER_IMPORT.md` — one-time 30–50 car data importer.
9. `08_AUTH_INLINE_EDITING.md` — admin login and public-page editing.
10. `09_TECH_STACK_DEPLOYMENT.md` — architecture and demo deployment.
11. `10_IMPLEMENTATION_PHASES.md` — suggested build order.
12. `11_CONTENT_BRAND_NOTES.md` — TerraAuto positioning/content notes.

## Reference sites

- TerraAuto Instagram: https://www.instagram.com/terraauto_/
